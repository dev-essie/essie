# Essie portfolio

A responsive portfolio inspired by the typographic structure of jeremy0x.dev, with original styling and Essie's own content.

## Development

Run `npm install`, then `npm run dev`. Production: `npm run build`.

## Content

Edit projects and biography in `app/page.tsx`; styles are in `app/globals.css`. Project artwork is an original typographic representation, not a screenshot of a client site. Contact currently points to the supplied GitHub profile; replace it with a confirmed email or social link when available.

Client project descriptions are based on Essie's supplied details. GitHub project descriptions and background are based on https://github.com/ESTIE-CREATOR. No client results or metrics are implied.
